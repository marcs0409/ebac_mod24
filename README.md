# EBAC - Módulo 24 - Bancos de Dados + SQL

Este projeto contém as atividades e exercícios realizados durante o Módulo 24 do curso de Cientista de Dados. O foco principal é a integração entre Python e SQL utilizando a biblioteca `sqlite3` e `pandas`.

## Conteúdo do Projeto

* **Profissao Cientista de Dados M24**: introdução ao SQL, execução de queries básicas, uso de cláusulas como `LIMIT` e funções de agregação (SUM, AVG).
* Exercícios práticos envolvendo uma base de dados de vendas (`TB_VENDAS_TAREFA.csv`), cobrindo:
    1. Consultas gerais de tabelas.
    2. Filtragem de linhas e colunas (SELECT, WHERE).
    3. Cálculos de média e renomeação de colunas (Alias).
    4. Operações matemáticas entre colunas para cálculo de valor total.
    5. Desafios de lógica SQL.
    6. Reflexões sobre a utilidade do SQL vs Python e bancos relacionais vs não relacionais.
